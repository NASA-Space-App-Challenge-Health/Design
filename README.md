# Design — T.H.A.I.S. (Astronaut Health Monitor)

Quick overview of visual identity, logo, and UI/UX design.

## Logo & Brand
* **Mission Patch:** Circular aerospace-inspired emblem with a deep-space navy gradient and metallic outer ring.
* **Identity:** Futuristic white typography paired with four glowing cyan HUD icons representing key biometric systems (ECG, brain, lungs, balance).

## UI & Colors
* **Dark Mode:** Deep space navy theme designed for low-light environments and high-contrast telemetry.
* **Status Indicators:** 
  * 🟢 **Green/Cyan:** Nominal / In Range
  * 🟡 **Amber:** Warnings / Request Help
  * 🔴 **Red:** Emergency / Critical

## Core Layout & Responsiveness
* **Navigation:** Sidebar/drawer organized by physiological systems (Overview, Blood & heart, Brain & balance, etc.) with a crew selector.
* **Desktop:** Fixed sidebar layout with multi-panel data visualization and live trend charts.
* **Mobile:** Compact mobile-first design featuring an interactive body map, stacked cards, and collapsible menus.
